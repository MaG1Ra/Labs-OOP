Обрабатывает динамический массив до первого отрицательного элемента. 

Функция ищет первый отрицательный элемент в массиве, затем если отрицательный элемент найден, создаётся новый массив, в котором находятся элементы до отрицательного, Старый массив освобождается, а указатель arr переходит на новый массив.
