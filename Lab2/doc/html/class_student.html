Подробное описание

Класс для представления студента в системе управления студентами.

Класс Student моделирует студента с личными данными и академической информацией. Класс обеспечивает корректность данных через проверку инвариантов.

Инварианты класса:

  • Возраст должен быть в диапазоне [16, 100]
  • Средняя оценка должна быть в диапазоне [0, 5]
  • Номер курса должен быть в диапазоне [1, 6]
Заметки
Класс содержит статический счётчик для отслеживания активных объектов.
