Подробное описание

Цвет в модели RGB: красная, зелёная и синяя составляющие в диапазоне 0–255.

Класс демонстрирует перегрузку операторов:

  • унарные ++ и -- в префиксной и постфиксной форме (увеличение и уменьшение яркости);
  • арифметическое присваивание +=, -=, *=, /=;
  • бинарные +, -, *, /, которые реализованы через +=, -=, *=, /=;
  • сравнение по яркости <, >, <=, >=, ==, !=.

Дополнительно в классе используются:

  • статическое поле RGBColor::counter, по которому определяется количество цветов в палитре;
  • деструктор, уменьшающий этот счётчик.
Заметки
Результаты всех операций ограничиваются диапазоном 0–255, переполнения не происходит.

Конструктор по умолчанию.

Создаёт чёрный цвет (0, 0, 0) и увеличивает счётчик цветов в палитре.

◆ luminance()

double RGBColor::luminance ( ) const
private

Вычисляет яркость цвета.

Яркость считается как сумма каналов: 0.2126 * R + 0.7152 * G + 0.0722 * B. По этому значению сравниваются цвета.

Возвращает
Яркость цвета (чем больше значение, тем цвет светлее).

Веса каналов соответствуют восприятию яркости человеком: зелёный вносит наибольший вклад, синий наименьший. Константы заданы как float, результат приводится к double.

◆ operator*=()

RGBColor & RGBColor::operator*= ( const RGBColor & rhs)

Умножение цветов с присваиванием (смешивание).

Каждый канал вычисляется как канал * rhs.канал / 255. Деление на 255 нужно, чтобы результат оставался в шкале 0–255: белый цвет (255) не меняет второй цвет, чёрный (0) даёт чёрный.

Аргументы
rhsЦвет, на который умножаем.
Возвращает
Ссылка на изменённый объект.

Деление нацело, дробная часть отбрасывается. Наибольшее произведение 255 * 255 = 65025 помещается в int.

◆ operator/=()

RGBColor & RGBColor::operator/= ( const RGBColor & rhs)

Деление цветов с присваиванием (операция, обратная умножению).

Каждый канал вычисляется как канал * 255 / rhs.канал, результат не превышает 255.

Заметки
Если канал делителя rhs равен 0, результат для этого канала равен 255, то есть деления на ноль не происходит.
Аргументы
rhsЦвет-делитель.
Возвращает
Ссылка на изменённый объект.

Сначала выполняется умножение на 255, и только потом деление, чтобы не потерять точность при целочисленном делении. Если канал делителя равен 0, результат равен 255 (защита от деления на ноль).
